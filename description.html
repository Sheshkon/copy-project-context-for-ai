Copy Project Context for AI copies selected files and folders from the Project View into a structured, AI-friendly document — ready to paste into ChatGPT, Claude, Gemini, Cursor, Continue, Aider, and other LLM tools.

Instead of manually copying file trees and contents, select what you need, choose Copy Selected to AI from the context menu, and get a formatted snapshot on your clipboard.

Features

  • Copy selected files, folders, or mixed multi-selection recursively
  • ASCII project tree for quick structural overview
  • File contents in language-aware Markdown code blocks
  • Respects .gitignore, .cursorignore, .aiderignore, and .copilotignore
  • Built-in ignore rules for build artifacts, dependencies, and binary files
  • Configurable limits for file count, total characters, and single file size
  • Settings page under Settings → Tools → Copy Project Context for AI

Supported IDEs

IntelliJ IDEA, PyCharm, WebStorm, GoLand, PhpStorm, CLion, RustRover, RubyMine, DataGrip, and other JetBrains IDEs based on the IntelliJ Platform (2024.2+).

How to use

  1. Select one or more files or folders in the Project View
  2. Right-click and choose Copy Selected to AI
  3. Paste the generated context into your AI assistant
